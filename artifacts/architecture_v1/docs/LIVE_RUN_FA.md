# اجرای واقعی و بازتولید ارزیابی

وضعیت: ارزیابی هر دو روش روی ۱۵ پروندهٔ توسعه و ۱۵ پروندهٔ آزمون کامل شد؛ هر ۱۰ سناریوی عملیاتی چندنوبتی نیز گذشتند. کد، داده و دستور مدل بین توسعه و آزمون تغییر نکردند. تعداد 3 پاسخ مقایسه‌ای ردشده در نتایج باقی‌اند و با ارجاع محافظه‌کارانه جایگزین شده‌اند.

مصرف: اجرای نهایی 83 درخواست واقعی با هزینهٔ محاسبه‌شدهٔ 0.18426804 دلار داشت. مجموع مصرف تأییدشده با آزمایش‌های قبلی 0.18985252 دلار است؛ مبلغ 0.00685397 دلار برای درخواست بی‌پاسخ ذخیره مانده است. موجودی پنل خوانده نشده است.

اختلال: تلاش نخست در پایان مهلت اتصال متوقف شد و هیچ پرونده‌ای ارزیابی نشد. هزینهٔ احتمالی آن حفظ و تلاش ناموفق جدا ذخیره شد. پس از بازگشت اتصال، یک شروع کنترل‌شده انجام شد؛ تکرار خودکار درخواست مدل وجود ندارد.

بودجه: سقف تجمعی این مرحله ۰٫۵۰ دلار و سقف خروجی هر فراخوانی ۱۰۰۰ توکن بود. دفتر مشترک حفظ شده و نباید پاک شود. کلید داخل فایل یا تنظیمات دائمی ذخیره نشده است. پاسخ خام مدل فقط در نهانگاه محلی خارج از بستهٔ تحویل قرار دارد.

مدرک: پاسخ‌های مقایسه‌ای، ردپاها، سناریوها، مصرف و قفل پیکربندی در مسیرهای زیر هستند:

محدودیت: موفقیت تطبیق نقل‌قول و سناریوهای عملیاتی، صحت معنایی همهٔ توصیه‌ها یا کیفیت سؤال‌ها را ثابت نمی‌کند. پاسخ‌های تکمیلی سناریوها طراحی‌شده‌اند و بازبین آن‌ها برنامه‌ریزی‌شده است. داوری مستقل انسانی و آزمون روی سایت هنوز باقی‌اند.

قرارداد: انتخاب شاهد در `model_selection.schema.json` و پاسخ داخلی پس از درج متن در `answer.schema.json` تعریف شده‌اند. قالب اجباری از [راهنمای رسمی پاسخ ساخت‌یافته](https://developers.openai.com/api/docs/guides/structured-outputs) پیروی می‌کند.

مرجع: نشانی پیش‌فرض از [راهنمای رسمی اتصال مستقیم متیس](https://docs.metisai.ir/api/wrapper/openai/) گرفته شده است. پوشش تمام امکانات همهٔ مدل‌ها تضمین نشده؛ نام مدل و امکان پاسخ ساخت‌یافته باید با همان حساب بررسی شوند.

## تنظیم محیط

راهنما: کلید را با ورودی پنهان وارد کنید. دستور نمونه مقدار واقعی کلید را در سابقهٔ ترمینال نمی‌نویسد. نام مدل و دو تعرفهٔ دلاری را با مقدار واقعی درگاه جایگزین کنید. تعرفه باید سربار متیس را هم دربرگیرد؛ اگر پنل فقط تومان نشان می‌دهد، تبدیل دلاری را بر اساس سهمیهٔ همین پروژه با منتور روشن کنید. برنامه با تعرفهٔ خالی اجرا نمی‌شود.

```powershell
$secret = Read-Host "Metis API key" -AsSecureString
$env:METIS_API_KEY = [System.Net.NetworkCredential]::new("", $secret).Password
$env:METIS_BASE_URL = "https://api.metisai.ir/openai/v1"
$env:METIS_MODEL = "REPLACE_WITH_AVAILABLE_MODEL"
$env:CASEPILOT_INPUT_USD_PER_MILLION = "REPLACE_WITH_ACTUAL_USD_RATE"
$env:CASEPILOT_OUTPUT_USD_PER_MILLION = "REPLACE_WITH_ACTUAL_USD_RATE"
$env:CASEPILOT_BUDGET_USD = "5"
$env:CASEPILOT_MAX_OUTPUT_TOKENS = "1200"
$env:CASEPILOT_MODE = "live"
python run.py doctor
```

محدودیت: مقدار پنج دلار برای کل تیم است. اگر بخشی از اعتبار قبلاً خارج از این برنامه مصرف شده، سقف را به باقی‌مانده کاهش دهید. اجرای برنامه روی چند لپ‌تاپ با دفترهای مستقل، سقف تیمی را حفظ نمی‌کند؛ یک سرور و یک دفتر مشترک داشته باشید. فایل دفتر را میان آزمایش‌ها پاک نکنید.

محل پیش‌فرض دفتر:

```text
runtime/team_budget.sqlite3
```

## نمونهٔ کوچک و سپس اجرای کامل

راهنما: ابتدا دو پروندهٔ توسعه و بدون سناریو اجرا کنید؛ خروجی و هزینه را بخوانید. این دستور با یک فراخوانی برای هر پرونده و هر روش، حداکثر چهار تلاش مدل دارد. پاسخ‌های موجود در حافظهٔ نهان دوباره هزینه نمی‌گیرند و با برچسب جدا ثبت می‌شوند.

```powershell
python scripts/evaluate.py --mode live --split dev --limit 2 --no-scenarios
```

بررسی: سازگاری مدل با مسیر گفت‌وگو، رعایت ساختار خروجی، زبان، کیفیت استناد، سقف توکن و قیمت واقعی را همین‌جا بسنجید. نام مدل یا دستور مدل را فقط با مجموعهٔ توسعه تنظیم کنید. بعد از تثبیت تنظیمات و اطمینان از بودجه، اجرا را گسترش دهید.

توضیح: نتیجهٔ نمونهٔ کوچک در پوشه‌ای جدا با پسوند نمونه ذخیره می‌شود و نتیجهٔ اجرای کامل را بازنویسی نمی‌کند. گزارش‌ساز نتایج آزمایشی و زنده و علت توقف را جدا می‌خواند؛ فایل فرم انسانی همچنان باید با داوری واقعی تکمیل شود.

```powershell
python scripts/evaluate.py --mode live --split dev
python scripts/evaluate.py --mode live --split test
```

حسابداری: پیش از شبکه یک ذخیرهٔ محافظه‌کارانه از هزینه در تراکنش ثبت می‌شود. ورودی با اندازهٔ بایتی و خروجی با سقف توکن برآورد می‌شوند. مصرف تأییدشده جای برآورد می‌نشیند. در قطع ارتباط یا مصرف نامعلوم، ذخیره حفظ می‌شود؛ تلاش خودکار دوباره وجود ندارد. تضمین نهایی سقف مصرف، به سهمیهٔ درگاه و درست‌بودن تعرفه وابسته است. حدود محلی نمی‌توانند پولی را که درگاه قبلاً مصرف کرده برگردانند.

نتیجه: پاسخ مدل و فراخوانی واقعی، پاسخ نهان‌شدهٔ اجرای قبلی و پاسخ قطعی آزمایشی سه وضعیت جدا هستند. فایل‌های آزمایشی را به نام اجرای واقعی تغییر ندهید. هزینهٔ آماده‌سازی، خطاهای درگاه و ارزیابی همگی جزو بودجه‌اند. بازیابی فعلی embedding نمی‌سازد و هزینهٔ آن صفر است.

## بازبینی انسانی و تکمیل گزارش

راهنما: فرم داوری را روی خروجی واقعی پر کنید؛ امتیاز شامل ارتباط شاهد، پشتیبانی ادعا، سازگاری نسخه، فایدهٔ سؤال، تکرارنکردن بررسی و نتیجهٔ مجاز است. فایل گزارش هزینه از دفتر واقعی ساخته می‌شود. نام و سهم اعضا را بر اساس مشارکت واقعی اضافه کنید.

```powershell
python scripts/write_report.py
python scripts/verify_package.py
```

امنیت: خطای درگاه بدون متن خصوصی پاسخ در گزارش ثبت می‌شود. کلید، توکن سرور و فایل محیط را وارد نوت‌بوک، گردش‌کار، نسخهٔ مخزن یا فایل تحویل نکنید. حافظهٔ نهان واقعی می‌تواند متن پرونده داشته باشد و پیش‌فرض وارد بستهٔ اشتراک نمی‌شود.
