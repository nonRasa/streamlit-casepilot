# معماری جاری پروژه

راهنما: مسیر پیش‌فرض برنامه اکنون معماری دوم است. شرح کامل مراحل، نمودار، قراردادها، هزینه و تطبیق با تمرین‌ها در [راهنمای معماری دوم](ARCHITECTURE_V2_FA.md) قرار دارد.

مسیر: استخراج اطلاعات ← اصلاح حافظه ← بازنویسی محدود پرسش ← امبدینگ پرسش با کش ← بازیابی واژگانی و برداری ← ادغام رتبه و تنوع ← بازرتبه‌بندی ← تولید پاسخ ← کنترل قطعی ← داور مدل ← حداکثر یک اصلاح و داوری دوباره ← پیشنهاد ← بازبینی انسانی ← اجرای مجاز محلی.

تاریخچه: توضیح معماری اول و کد قفل‌شدهٔ ارزیابی قبلی در پوشهٔ `architecture_v1` نگه‌داری شده‌اند. نتایج آن ارزیابی، کیفیت معماری دوم را تأیید نمی‌کنند.
